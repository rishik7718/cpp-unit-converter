# 📏 C++ Unit Converter

A beginner-friendly console-based Unit Converter built using C++.

## 📌 Description

This project converts units between **Kilometers (km)**, **Meters (m)**, and **Centimeters (cm)**. It was developed to strengthen my understanding of C++ fundamentals such as conditional statements, user input, arithmetic operations, and program logic.

This project was built completely as part of my C++ learning journey before starting my first semester of Computer Science Engineering.

---

## ✨ Features

- ✅ Kilometer ↔ Meter conversion
- ✅ Kilometer ↔ Centimeter conversion
- ✅ Meter ↔ Centimeter conversion
- ✅ Supports conversions in both directions
- ✅ Handles invalid user input
- ✅ Simple console-based interface

## 🚀 How to Run

1. Compile the program

```bash
g++ main.cpp -o unit_converter
```

2. Run the executable

```bash
./unit_converter
```

(Windows users can run `unit_converter.exe`.)
